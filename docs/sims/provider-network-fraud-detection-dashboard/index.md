## About This MicroSim

This four-panel dashboard summarizes fraud indicators across a provider network with $128.5M in billing over 18 months and an estimated $31.2M (24%) in fraud. The panels rank the top providers by composite risk score (color-coded by tier), trace four fraud indicators rising over 24 months, compare the precision and recall of four detection algorithms (the combined model is best), and break down the financial impact into estimated fraud, amounts recovered year-to-date, and clean billing.

## How to Use

Hover over any bar, line, or segment for exact values — the risk-ranking tooltip also shows each provider's estimated financial exposure. Compare the rising trend lines to see how organized schemes grow over time, and compare the algorithm precision and recall bars to see why combining detection methods outperforms any single one.
