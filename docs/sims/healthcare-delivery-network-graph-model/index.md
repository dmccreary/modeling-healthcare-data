## About This MicroSim

This graph models a regional healthcare delivery network — the web of places and people that deliver care. A hospital OPERATES an emergency department and outpatient facilities (surgical center, imaging center); clinics are AFFILIATED_WITH the hospital; providers WORK_AT clinics; clinics REFER_TO each other and to outpatient facilities; and patients are attributed to a primary-care provider. Modeling the network as a graph supports questions about referral paths, capacity, and access across facility types.

## How to Use

Read each node's shape and color against the legend to identify facility and provider types, then follow the labeled edges to see how the network fits together — for example, a patient's PCP works at Downtown Primary Care, which is affiliated with the Regional Medical Center and refers to Cardiology Associates and the imaging center. Drag nodes and use the navigation buttons to untangle and explore the network.
