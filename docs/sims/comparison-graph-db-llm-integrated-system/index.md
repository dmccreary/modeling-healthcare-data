## About This MicroSim

This grouped bar chart compares a standalone graph database, a standalone large language model, and an integrated system across seven healthcare-AI capabilities, scored 0-10 from a 500-question clinical QA benchmark. The graph database excels at factual accuracy, explainability, and relationship reasoning but cannot understand natural language; the LLM is the reverse; and the integrated system captures the strengths of both. Note that the Hallucination axis is inverted, so a high score means low hallucination.

## How to Use

Hover over any bar to see its exact score. Compare the three bars within each capability to see where each standalone approach is strong or weak, and scan across to see how the integrated system (green) reaches the top of nearly every dimension — the best-of-both-worlds result of grounding an LLM in a graph.
